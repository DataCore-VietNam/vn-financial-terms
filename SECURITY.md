# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| 0.1.x   | No        |

## Reporting a vulnerability

Email **dev@datacore.vn** with subject line `[SECURITY] vn-financial-terms`.

Please include a description of the issue and steps to reproduce. We aim
to acknowledge within 48 hours and resolve critical issues within 7 days.

Do not open a public GitHub issue for security vulnerabilities.
